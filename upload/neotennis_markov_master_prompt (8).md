### ۱. اصلاح فرمول محاسبه ضریب `1xBet` در `src/lib/tennis/supervisor.ts` (تقسیم بر مارجین واقعی به جای ضرب!)

در فایل `src/lib/tennis/supervisor.ts`، تابع `fairPrice` و ثابت‌های مارجین را با فرمول استاندارد مارجین ۵.۵٪ تا ۶.۵٪ سایت `1xBet` جایگزین کن و **برش‌های مصنوعی `clampPrice` را که ضریب را تحریف می‌کنند حذف کن**:

```typescript
// ضرایب اورراند واقعی سایت 1xBet در مارکت‌های تنیس:
const ONEXBET_OVERROUND_MAIN = 1.052;   // ۵.۲٪ کارمزد در خط اصلی برد/ست
const ONEXBET_OVERROUND_PROP = 1.065;   // ۶.۵٪ کارمزد در خط مجموع گیم و کمبو
const ONEXBET_OVERROUND_EXOTIC = 1.075; // ۷.۵٪ کارمزد در سناریوهای دقیق

// فرمول صحیح ضریب واقعی تابلوی 1xBet (تقسیم بر اورراند، بدون برش مصنوعی!):
export function computeReal1xBetTennisOdds(trueProb: number, overround = ONEXBET_OVERROUND_MAIN): number {
  const safeProb = Math.max(0.06, Math.min(0.90, trueProb));
  const raw1xBetOdds = 1 / (safeProb * overround);
  return Number(Math.max(1.14, Math.min(12.0, raw1xBetOdds)).toFixed(2));
}
```

### ۲. حذف ضرایب ثابت `1.97x / 2.68x` در تب ۱ و انتخاب هوشمند خط گیم متناسب با قدرت فاوریت

در تب اول (`زوج‌تیپ مکمل`)، هرگز ضرایب ثابت `1.97` و `2.68` را چاپ نکن! ضریب تیپ A و تیپ B را مستقیماً با `computeReal1xBetTennisOdds(probA)` و `computeReal1xBetTennisOdds(probB)` محاسبه کن:
- اگر بازیکن اول فاوریت بسیار سنگین است (مثل *Carlos Alcaraz* که احتمال برد ۲-۰ او بالای ۵۸٪ است و ضریب `2-0` او در `1xBet` حدود `1.45x` می‌شود)، به صورت خودکار مارکت تیپ A را به **`MARKET: GAME HANDICAP — FAVORITE -4.5 GAMES` (یا `TOTAL GAMES: UNDER 20.5 GAMES` با احتمال ~۴۸٪ و ضریب واقعی `~1.96x` در `1xBet`)** و تیپ B را به **`MARKET: TOTAL GAMES — OVER 20.5 GAMES` (یا `FAVORITE WINS 2-1` با ضریب واقعی `~2.45x تا 3.10x`)** تغییر بده تا ضریب هر دو بال در سایت `1xBet` واقعاً در بازه قابل داچینگ (`1.80x تا 3.20x`) قرار بگیرد!
- در تب ۳ (`کمبوی کاپولا`)، اگر یک بال احتمال ۷۰٪ دارد، ضریب واقعی آن (`1.34x`) را تغییر نده؛ یا دو بالی را انتخاب کن که احتمالشان در مونت‌کارلو حدود `46%` و `42%` است تا ضرایب واقعی آن‌ها در `1xBet` حدود **`2.04x` و `2.24x`** باشد!
